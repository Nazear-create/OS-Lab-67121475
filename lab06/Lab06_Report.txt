1. FIFO vs LRU (Phase 2):
เมื่อกำหนดให้มีหน่วยความจำ 3 Frames ผลที่ได้คือ FIFO เกิด Page Fault 9 ครั้ง ส่วน LRU เกิด 7 ครั้ง 
ความแตกต่างนี้มาจากวิธีเลือก Page ออกจากหน่วยความจำ โดย FIFO พิจารณาตามลำดับที่โหลดเข้ามา 
ขณะที่ LRU พิจารณาจากเวลาที่ถูกเรียกใช้ล่าสุด เนื่องจากข้อมูลในการทดลองมีการใช้งาน Page เดิมซ้ำในระยะเวลาสั้น ๆ 
วิธี LRU จึงสามารถเก็บ Page เหล่านั้นไว้ใช้งานต่อได้ และลดจำนวน Page Fault ได้ดีกว่า FIFO ในกรณีนี้

2. Understanding Thrashing (Phase 3):
Thrashing เกิดขึ้นเมื่อหน่วยความจำหลักรองรับ Page ที่โปรแกรมต้องใช้งานได้ไม่เพียงพอ ระบบจึงต้องย้าย Page 
เข้าและออกจาก RAM บ่อยครั้ง จนเสียเวลากับการจัดการหน่วยความจำมากกว่าการทำงานของโปรแกรม 
ส่งผลให้ระบบทำงานช้าลงอย่างมาก

ในการทดลอง Scenario 1 ทำงานเสร็จภายใน 0.3699 วินาที ขณะที่ Scenario 2 ใช้เวลา 1.5645 วินาที 
หรือประมาณ 4.23 เท่า โดย Scenario 1 จัดการข้อมูลใน RAM ส่วน Scenario 2 ต้องดำเนินการกับไฟล์ซ้ำหลายรอบ 
ทั้งการเปิด อ่าน เขียน และปิดไฟล์ จึงมีขั้นตอนและภาระการทำงานเพิ่มขึ้น

ผลดังกล่าวแสดงให้เห็นค่าใช้จ่ายด้านเวลาของการจัดการไฟล์ แต่ยังไม่ใช่หลักฐานของการเกิด Thrashing จริง 
เนื่องจากโค้ดไม่ได้บังคับให้ระบบปฏิบัติการสลับ Page และข้อมูลไฟล์บางส่วนอาจถูกเก็บไว้ในแคช จึงไม่ควรตีความว่าเป็น
การเปรียบเทียบความเร็วระหว่าง RAM และดิสก์โดยตรง
