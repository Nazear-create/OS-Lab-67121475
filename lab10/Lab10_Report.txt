1. The Role of the Operating System

File System & Permissions:
โปรแกรมตรวจว่า Dataset มีอยู่ด้วย os.path.exists(dataset_path) ก่อนจัดสรรทรัพยากร โดย Workload D ถูกปฏิเสธเพราะไม่พบ secret_keys.txt 
ทั้งนี้เป็นเพียงการตรวจการมีอยู่ของไฟล์ ไม่ใช่การตรวจสิทธิ์อ่านอย่างครบถ้วน

Memory Management:
งานจะรอหาก RAM ไม่เพียงพอ และใช้ ram_lock ป้องกันหลาย Thread แก้ไขยอด RAM พร้อมกัน โดยหักทรัพยากรเมื่อจัดสรรและคืนหลังทำงานเสร็จ 
กลไกนี้จำลองการควบคุมการใช้หน่วยความจำเพื่อลดความเสี่ยง Thrashing แต่ไม่ได้ใช้ RAM หลาย GB จริง และการทดลองนี้มี RAM เพียงพอสำหรับทั้งสามงาน

Concurrency & Deadlocks:
แต่ละงานมี Worker Thread ของตนเอง และใช้ sorted(req_gpus) เรียงลำดับการขอ GPU เช่น เปลี่ยน [2, 1, 0] เป็น [0, 1, 2] การขอ Lock ตามลำดับเดียวกันช่วยป้องกัน 
Circular Wait ระหว่าง GPU Locks
